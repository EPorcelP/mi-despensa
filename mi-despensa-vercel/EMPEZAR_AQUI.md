# Orden de puesta en marcha

1. Abre esta carpeta en Visual Studio Code.
2. Sigue `README.md`, empezando por Supabase.
3. Ejecuta en Supabase `supabase/001_setup.sql` y después `supabase/002_inventario_inicial.sql`.
4. Copia `.env.example` a `.env.local` y completa sus valores.
5. Ejecuta `npm ci` y `npm run dev` para probar.
6. Sube la carpeta a un repositorio privado de GitHub e impórtalo en Vercel.
7. Añade las variables de entorno en Vercel y despliega.
8. Configura el subdominio y graba su URL en la etiqueta NFC.

Acceso privado con contraseña propia, independiente de ChatGPT. Diseño mobile-first. Guardado común entre dispositivos.
